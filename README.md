# 記念日カード（anniversary-card）

開業日を入れると、今日で何日目かと次に来る節目3つが分かります。その節目の記念カード画像（1080×1080）をその場で保存できます。

100日100プロダクトチャレンジ Day047。

## 使い方

1. 名前（全角16文字・半角32文字まで）と起点日（開業日・オープン日など）を入れる
2. 呼び方を選ぶ（開業／オープン／創業／はじめて／結婚記念日／その他）。一言は任意
3. 「カードにする日」を今日か、次の節目3つから選ぶ
4. 色を選んで「記念カードを保存」

## 数えかた

**起点日当日を1日目として数えます。**

次の節目は3系統から1つずつ出します。

| 系統 | 取り方 |
|---|---|
| 100日刻み | 今日の日目より大きい、最小の100の倍数 |
| 1000日刻み | 今日の日目より大きい、最小の1000の倍数 |
| 周年 | 起点日の月日で次に来る年 |

3件が同じ日になる場合は、後ろの節目へずらして常に別々の3件にします。
2月29日が起点日のときは、うるう年でない年の周年を3月1日として数えます。

日数の計算は年月日だけを使い、`Date.UTC` で正規化した値の差で出しています。時刻を使わないので、夏時間やタイムゾーンで1日ずれることはありません。

## 出力

| 項目 | 仕様 |
|---|---|
| 形式 | PNG・1080×1080（1:1） |
| ファイル名 | `kinenbi-YYYYMMDD.png`（カードにした日付） |
| 配色 | 6種。カード内の文字と背景のコントラスト比はいずれも 4.70 以上（WCAG AA の 4.5 以上） |

## 作っていないもの

複数の記念日の保存・管理、通知、SNS用の文章生成、ストーリーズ（9:16）やA4などの他の形式、写真の差し込み、節目の自由指定、和暦・六曜・祝日の判定。

## 技術

HTML/CSS/JavaScript 1ファイル。ビルドなし、npmなし、外部ライブラリなし、画像アセットなし。カードは canvas 2D の図形と文字だけで描いています。

入力した内容はブラウザの中だけで扱い、送信も保存もしません（localStorage も使っていません）。外部通信はアクセス解析（Cloudflare Web Analytics）のビーコン1本だけです。

検証スクリプトと撮影ハーネスは運用リポジトリ側（`work/100days/products/day-047/tools/`）に置いています。
